# Logo SaytuMbay v11

Tracés exacts du logo officiel (vectoriels, sans masque), dans trois formats :

| Dossier | Usage |
|---|---|
| `svg/` | Web, interface, impression (source de vérité) |
| `pdf/` | Imprimeur, documents |
| `png_transparent/`, `png_sur_fond/` | Réseaux sociaux, présentations, messagerie |

Variantes : horizontal, vertical, signe seul, signe réduit (sous 40 px), avatar carré ; en couleur, inversé (fond sombre) et sur bleu.
Couleurs d'origine des fichiers v11 : vert #0F6B45, bleu #1597B3, texte #0A1F1A ; sur fond sombre vert #2BD47D et bleu #4FD8EF.
La charte graphique v1.0 (octobre 2026) les remplace : disque vert forêt #0F5A44, orbite et capteur orange signal #EF6A22, texte nuit #0B2E24 ; sur fond sombre, disque et texte sable #F4EFE6. Le site applique ces couleurs par variables CSS ; les fichiers de ce dossier restent à remplacer par ceux de la charte (`brand-identity/02-logos/svg`).
