# Signaler une faille de sécurité

Merci de nous aider à protéger les producteurs et les organisations qui utilisent SaytuMbay.

**N'ouvrez pas de ticket public** pour une faille. Écrivez à **contact@saytumbay.com** avec :

- ce que vous avez trouvé et où (adresse, page, partie du code) ;
- comment le reproduire ;
- ce qu'un attaquant pourrait en faire.

Nous accusons réception sous 5 jours ouvrés et vous tenons informé jusqu'à la correction. Merci de nous laisser le temps de corriger avant toute publication.

Ce qui est concerné : le site https://saytumbay-plateforme.vercel.app, la future plateforme et le code de ce dépôt. La démo en ligne tourne entièrement dans le navigateur, avec des données simulées : aucune donnée réelle n'y est stockée.

Merci de ne pas accéder aux données d'autrui, de ne pas perturber le service et de ne pas faire d'ingénierie sociale.

La procédure complète est aussi sur la page `/securite` du site et dans `/.well-known/security.txt`.
